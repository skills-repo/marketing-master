# 着陆页设计与优化

> 着陆页是用户的第一印象，也是转化漏斗的入口。为独立开发者设计高转化率的着陆页。

## 能力

- **页面结构**：Hero 区、功能展示、社会证明、定价、FAQ 经典五段式
- **文案撰写**：标题公式、副标题层级、功能描述 vs 用户收益
- **CTA 设计**：按钮文案、位置策略、紧迫感营造
- **A/B 测试**：测试假设生成、变体设计、结果分析
- **转化优化**：表单简化、信任信号、异议处理

## 使用方式

```
/landing-page-builder 为我的 API 工具设计一个着陆页结构
/landing-page-builder 分析这个着陆页的转化问题：{url}
/landing-page-builder 给我 3 个 Hero 区标题的 A/B 测试方案
```

## 工作流

1. 描述产品或提供现有页面 URL
2. AI 分析当前页面的转化瓶颈
3. 生成优化方案（结构/文案/CTA）
4. 提供 A/B 测试假设和变体
5. 输出可直接实施的代码/文案修改

## 着陆页检查清单

| 区域 | 检查点 |
|------|--------|
| Hero | 5 秒内能看懂产品做什么吗？ |
| 功能 | 说的是用户得到什么，不是产品有什么？ |
| 社会证明 | 有真实的用户评价或数据吗？ |
| 定价 | 价格对比清晰吗？有免费选项吗？ |
| CTA | 按钮醒目吗？文案是动作导向吗？ |

## 适用场景

- 新产品着陆页从零搭建
- 已有着陆页转化率低需要优化
- A/B 测试方案设计
- 多版本着陆页（不同渠道/受众）

## 限制

- 不涉及前端代码实现（仅提供设计指导）
- 不涉及后端表单/支付集成
- 转化率受流量质量影响，不保证具体数字
